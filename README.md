## 📁 Featured Projects

### 1. LaTech — Weekly AI & Tech Intelligence Digest
A personal intelligence dashboard delivering hand-curated, AI-generated weekly digests of the most important AI developments and trending open-source repositories. Fully automated via Make.com pipelines feeding a Supabase backend.

- **Stack:** Next.js 14, TypeScript, Supabase, Make.com, TailwindCSS
- **Live:** [latech-lac.vercel.app](https://latech-lac.vercel.app/)
- **Source:** [github.com/Isaac06272/latech](https://github.com/Isaac06272/latech)

### 2. Nappr — Location-Based Alarm App
A precision location-based alarm application built for mobile platforms. Utilizes real-time background geofencing to wake users up exactly when they arrive at their destination via public transit.

- **Stack:** Flutter, Dart, Geofencing APIs, Local Push Notifications
- **Source:** [github.com/Isaac06272/nappr](https://github.com/Isaac06272/nappr)

### 3. QuizCraft — AI-Powered Study Platform
An AI-powered educational platform that automatically generates customized quizzes and flashcard decks from user-provided notes. Features dynamic difficulty scaling and progress tracking.

- **Stack:** React, Node.js, LLM APIs, MongoDB, TailwindCSS
- **Live:** [quizcraft-one.vercel.app](https://quizcraft-one.vercel.app/)
- **Source:** [github.com/Isaac06272/quizcraft](https://github.com/Isaac06272/quizcraft)

## 🏃‍♂️ Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
